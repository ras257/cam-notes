\chapter{1D Solutions of TISE}
\section{Bound States}
We would like to find the eigenstates and eigenvalues of the operator $\hat{H}$ for various potentials $U(x)$ as this allows us to express any state $\psi$ as a linear combination of such eigenstates.

When we expand $\hat{H} \chi = E \chi$, we have:
\[
  -\frac{\hbar^2}{2m} \chi''(x) + U(x) \chi(x) = E \chi(x)
\]
So if $U(x)$ is finite, then any eigenfunction $\chi(x)$ must be twice differentiable.
Otherwise, if $U(x)$ is infinite in some regions, then $\chi$ is continuous but $\chi'$ will not be.
\subsection{Infinite Potential Well}
Suppose the potential $U$ is given by:
\[
  U(x) = \begin{cases}
  0 & \text{ if } |x| \leq a \\
  \infty & \text{ if } |x| > a
  \end{cases}
\]
where $a \in \R^{+}$ is some constant.
This is \textit{the infinite potential square well}.

For $|x| > a$, we must have $\chi(x) = 0$ otherwise we would have $U\chi = \infty$.
For $|x| \leq a$, we want to solve:
\[
  \chi'' + \frac{2mE}{\hbar^2} \chi = 0
\]
with the continuity condition $\chi(a) = \chi(-a) = 0$.

If $E < 0$, then we always obtain the null state after applying the continuity conditions.
Thus to look for eigenstates, we must have $E \geq 0$ and so we define $k^2 = \frac{2mE}{\hbar^2} \geq 0$.
In this case, we have:
\[
  \chi'' + k^2 \chi = 0 \implies \chi(x) = A\sin(kx) + B\cos(kx)
\]
for constants $A$ and $B$.

Applying the continuity conditions, we obtain that both $A\sin(ka) = 0$ and $B\cos(ka) = 0$.
We need both of these to hold and $\chi$ to not be identically 0.
Since $\sin(ka)$ and $\cos(ka)$ cannot both be simultaneously 0, there are two options:
There is therefore two options:
\begin{enumerate}
  \item We have $A = 0$ and $B \neq 0$, thus $k_n = n \cdot \frac{\pi}{2a}$ for odd $n \geq 1$.
    Substituting in, we obtain the eigenfunctions:
    \[
      \chi_n(x) = B \cos(k_n x)
    \]
    for odd $n \in \N$.
  \item We have $B = 0$ and $A \neq 0$, thus $k_n = n \cdot \frac{\pi}{2a}$ for even $n \geq 2$.
    Substituting in, we obtain the eigenfunctions:
    \[
      \chi_n(x) = A \sin(k_n x)
    \]
    for even $n \in \N$.
\end{enumerate}
Having found $k_n = n \cdot \frac{\pi}{2a}$ for $n \geq 1$, we can find the eigenvalues $E_n$ for $\hat{H}$:
\[
  E_n = \frac{\hbar^2}{2m} k^2_n = \frac{\hbar^2\pi^2}{8ma^2}n^2 \text{ for } n \geq 1
\]
which are therefore only allowed energy levels for particles in the system.

We would like our stationary states to be normalised and so we can determine $A$ and $B$ by imposing that:
\[
  \int_{-a}^{a} |\chi_n(x)|^2 \d{x} = 1 \implies A = B = e^{i\alpha}\sqrt{\frac{1}{a}} \text{ for some } \alpha \in \R
\]
For convenience, we pick $\alpha = 0$ so that $A, B \in \R$ and so out eigenfunctions will also be real.
Thus the eigenfunctions of $\hat{H}$ with this potential are:
\[
  \chi_n(x) = \begin{cases}
  \sqrt{\frac{1}{a}} \cos\left(\frac{n \pi x}{2a}\right) & \text{ if } n \in \{1, 3, 5, \ldots\} \text{ and } |x| \leq a \\
  \sqrt{\frac{1}{a}} \sin\left(\frac{n \pi x}{2a}\right) & \text{ if } n \in \{2, 4, 6, \ldots\} \text{ and } |x| \leq a \\
  0 & \text{ if } |x| \geq a
  \end{cases}
\]
Graphically, the first three of these, which correspond to the three lowest energy states are:

We note that $\chi_n$ is always an even function for odd $n$ and an odd function for even $n$.
In fact, for any even potential $U$, eigenfunctions of $\hat{H}$ must be either even or odd functions.
\begin{lemma}
  For a quantum system with non-degenerate eigenvalues, if $U(x) = U(-x)$, then the eigenfunctions of $\hat{H}$ have to be either odd or even functions. \label{evenOddEF}
\end{lemma}
\begin{proof}
  Since $U(x) = U(-x)$, the TISE is invariant under $x \mapsto -x$.
  So if $\chi(x)$ is an eigenfunction with eigenvalue $E$, then $\chi(-x)$ is also an eigenfunction with eigenvalue $E$.
  Since the eigenvalues are non-degenerate, $\chi(-x)$ must be $\chi(x)$ up to some constant multiplicative factor $\lambda$, i.e. $\chi(x) = \lambda\chi(-x)$ for some $\lambda \in \C$.

  We then have:
  \[
    \chi(x) = \chi(-(-x)) = \lambda^2 \chi(x) \implies \lambda^2 = 1 \implies \lambda = \pm 1
  \]
  So $\chi(x) = \pm\chi(-x)$, i.e. the eigenfunction is either even or odd.
\end{proof}
\subsection{Finite Potential Well}
We can also have a potential well which is finite.
Suppose the potential $U$ is given by:
\[
  U(x) = \begin{cases}
  0 & \text{ if } |x| \leq a \\
  U_0 & \text{ if } |x| > a
  \end{cases}
\]
where $a \in \R^{+}$ is some constant and $U_0 < \infty$.

We will look for eigenfunctions with $0 \leq E \leq U_0$, the case of $E > U_0$ is an example of a scattering state and will be explored later.
We see that $U(x) = U(-x)$ and so by \cref{evenOddEF}, we need only look for even or odd eigenfunctions.
Here we will look only for even functions, but we will also look for the odd eigenfunctions of this on Example Sheet 2.

Unlike in the case of the infinite potential well, the solution is not necessarily trivial for $|x| \geq 0$ and so we need to solve slightly different cases of the TISE in two regions:
\[
  \begin{cases}
  -\frac{\hbar^2}{2m}\chi''(x) = E \chi(x) & \text{ for } |x| \leq a \\
  -\frac{\hbar^2}{2m}\chi''(x) = (E - U_0)\chi(x) & \text{ for } |x| > a
  \end{cases}
\]
Since $E \geq 0$, we let $k = \sqrt{\frac{2mE}{\hbar^2}}$ so that for $|x| \leq a$ we have:
\[
  \chi''(x) + k^2 \chi(x) = 0 \implies \chi(x) = A \sin(kx) + B \cos(kx)
\]
Since we are looking for even solutions, we must have $A = 0$.

Since $E \leq U_0$, we let $\overline{k} = \sqrt{\frac{2m(U_0 - E)}{\hbar^2}}$ so that for $|x| < a$ we have:
\[
  \chi''(x) - \overline{k}^2 \chi(x) = 0 \implies \chi(x) = Ce^{\overline{k} x} + De^{-\overline{k} x}
\]
We need this function to be square integrable, thus it must be bounded so for $x > a$ we need $C = 0$ and for $x < -a$ we need $D = 0$.
Further, since $\chi(x)$ is even, we must have $C = D$.

In summary:
\[
  \chi(x) = \begin{cases}
  Ce^{\overline{k} x} & \text{ if } x < -a \\
  B\cos(kx) & \text{ if } |x| \leq a \\
  Ce^{-\overline{k} x} & \text{ if } x > a
  \end{cases}
\]
Since $\chi(x)$ must be even, we have $C = D$.

Imposing continuity at $x = \pm a$ gives us:
\[
  Ce^{-\overline{k} a} = B \cos(ka)
\]
and imposing continuity of $\chi'$ at $x = \pm a$ gives us:
\[
  -\overline{k} C e^{-\overline{k} a} = -k B \sin(ka)
\]

To find $C$ and $B$, we first want to find the values of $k$.
Taking the ratio of the continuity equations we obtain:
\[
  k \tan(ka) = \overline{k}
\]
Further, from the definitions of $k$ and $\overline{k}$:
\[
  k^2 + \overline{k}^2 = \frac{2mU_0}{\hbar^2}
\]
Thus we want to find the intersection of the graphs $k \tan(ka) = \overline{k}$ and $k^2 + \overline{k}^2 = \frac{2mU_0}{\hbar^2}$.
Rescaling the variables using $\xi = ka$ and $\eta = \overline{k} a$, we are looking for the intersections of $\xi \tan \xi = \eta$ and $\chi^2 + \eta^2 = r^2_0$ where $r^2_0 = \frac{2mU_0}{\hbar^2}a^2$.
Graphically:
\begin{center}
\begin{tikzpicture}[>=stealth]
  \draw[->] (0, 0) -- (0, 5) node[right] {$\eta$};
  \draw[->] (0, 0) -- (11, 0) node[right] {$\xi$};

  \draw[thick, domain=0:1, smooth, variable=\x, scale=3] plot ({\x}, {\x * tan(\x r)}) node[right] {$\xi \tan \xi$};
  \draw[thick, domain=3.14:3.55, smooth, variable=\x, scale=3] plot ({\x}, {\x * tan(\x r)});
  \clip (0, 0) rectangle (5, 5);
  \draw[thick] (0, 0) circle (3cm);
  \node at (4, 1) {$\xi^2 + \eta^2 = r^2_0$};
\end{tikzpicture}
\end{center}
We will always have at least one intersection, and as the value of $r_0$ increases, we can get any finite number of intersections $p$.

Thus the eigenvalues of $\hat{H}$ correspond to these $p$ intersections:
\[
  E_n = \frac{\hbar^2}{2ma^2} \xi^2_n
\]
where $\xi_n$ are $\xi$-coordinates at the points of intersection for $n \in \{1, \ldots, p\}$.
\begin{remark}[Remarks]
  \begin{enumerate}
    \item We can use the continuity conditions to determine $C$ in terms of $B$ and then impose normalisation to determine $C$.
    \item Because of the exponential terms, these solutions have non-zero probability for $|x| > a$ which is forbidden classically.
  \end{enumerate}
\end{remark}
\subsection{Harmonic Oscillator}
Suppose the potential $U$ is given by:
\[
  U(x) = \frac{1}{2} kx^2 = \frac{1}{2} m\omega^2 x^2
\]
where $k \in \R^{+}$ is the \textit{elastic constant} and $\omega = \sqrt{\frac{k}{m}}$.
Recall from IA Differential equations that in classical mechanics we had:
\[
  \ddot{X}(t) = - \omega^2 X(t) \implies X(t) = A \sin(\omega t) + B \cos(\omega t)
\]
So $\omega$ is the frequency of the analogous classical harmonic oscillator.

However in quantum mechanics, we look for normalised eigenfunctions of $\hat{H}$, i.e. $\chi(x)$ satisfying:
\[
  -\frac{\hbar^2}{2m} \chi''(x) + \frac{1}{2} m \omega^2 x^2 \chi(x) = E \chi(x)
\]
Since $U$ is an even function, by \cref{evenOddEF}, we will only have even or odd eigenfunctions.

Looking for eigenfunctions becomes easier if we perform the change of variables:
\[
  \xi^2 = \frac{m\omega}{\hbar} x^2 \text{ and } \varepsilon = \frac{2E}{\hbar \omega}
\]
which gives:
\[
  -\deriv[2]{}{\xi} \chi(\xi) + \xi^2 \chi(\xi) = \varepsilon \chi(\xi)
\]
Starting with the case $\varepsilon = 1$, i.e. $E_0 = \frac{\hbar \omega}{2}$, by inspection, we find the normalisable solution:
\[
  \chi_0(x) = \exp\left(-\frac{\xi^2}{2}\right)
\]
since:
\[
  \deriv{\chi}{\xi} = - \xi \chi \implies \deriv[2]{\chi}{\xi} = (\xi^2 - 1)\chi \implies -\deriv[2]{\chi}{\xi} + \xi^2 \chi = 1 \cdot \chi
\]
To find the other eigenvalue-eigenfunction pairs, we look for a general solution of the form:
\begin{align*}
  \chi(\xi) &= f(\xi) \exp\left(-\frac{\xi^2}{2}\right) \\
  \implies \deriv{\chi}{\xi} &= \left(\deriv{f}{\xi} - \xi f\right)\exp\left(-\frac{\xi^2}{2}\right) \\
  \implies \deriv[2]{\chi}{\xi} &= \left(\deriv[2]{f}{\xi} - 2 \xi \deriv{f}{\xi} + (\xi^2 - 1)f\right) \exp\left(-\frac{\xi^2}{2}\right)
\end{align*}
and so:
\begin{align*}
  &\varepsilon f(\xi) \exp\left(-\frac{\xi^2}{2}\right) = \left(-\deriv[2]{f}{\xi} - 2 \xi \deriv{f}{\xi} - (\xi^2 - 1)f + \xi^2 f\right)\exp\left(-\frac{\xi^2}{2}\right) \\
  &\implies - \deriv[2]{f}{\xi} + 2 \xi \deriv{f}{\xi} + (1 - \varepsilon)f = 0
\end{align*}
The point $\xi = 0$ is an ordinary point of this equation and so we look for a power series solution about $\xi = 0$:
\begin{align*}
  f(\xi) = \sum_{n = 0}^{\infty} a_n \xi^n \implies f'(\xi) &= \sum_{n = 1}^{\infty} na_n \xi^{n - 1} \\
  \implies f''(\xi) &= \sum_{n = 2}^{\infty} n(n - 1) a_n \xi^{n - 2} = \sum_{n = 0}^{\infty} (n + 2)(n + 1)a_{n + 2} \xi^{n}
\end{align*}
and so:
\[
  \sum_{n = 0}^{\infty} [(n + 1)(n + 2)a_{n + 2} - 2na_n + (\varepsilon - 1)a_n]\xi^{n} = 0
\]
which yields the following recurrence relation:
\begin{equation}
  a_{n + 2} = \frac{(2n - \varepsilon + 1)}{(n + 1)(n + 2)}a_n \label{coeffRel}
\end{equation}
As mentioned, the eigenfunctions must be either even or odd functions of $\xi$.
If $f$ is an odd function, i.e. $f(\xi) = -f(-\xi)$, then taking $\xi = 0$ tells us that $a_0 = 0$, thus $a_n = 0$ for all even $n$.
If $f$ is instead an even function, i.e. $f(\xi) = f(-\xi)$, then its derivative $f'(\xi) = -f'(-\xi)$ is even, so taking $\xi = 0$ tells us that $a_1 = 0$, so $a_n = 0$ for all odd $n$.
\begin{proposition}
  If the series solution for $f(\xi)$ does not terminate, then it is not normalisable.
\end{proposition}
\begin{proof}
  Suppose the series does not terminate.

  From the recurrence relation, we see that the coefficients follow the asymptotic relation as $n \to \infty$:
  \[
    \frac{a_{n + 2}}{a_n} \sim \frac{2}{n}
  \]
  This is the same asymptotic behaviour as the coefficients of the Taylor series for the function:
  \[
    \exp(\xi^2) = \sum_{m = 0}^{\infty} \frac{\xi^{2m}}{m!} = \sum_{m = 0}^{\infty} b_m \xi^{m}
  \]
  where:
  \[
    b_n = \begin{cases}
    \frac{1}{m!} & \text{ for } n = 2m \\
    0 & \text{ for } n = 2m + 1
    \end{cases}
  \]
  and so as $n \to \infty$, the asymptotic behaviour of the coefficients for even $n$ as $n \to \infty$ is:
  \[
    \frac{b_{n + 2}}{b_n} = \frac{(n / 2)!}{(n/2 + 1)!} = \frac{2}{n + 2} \sim \frac{2}{n}
  \]
  Thus if the series solution for $\xi$ does not terminate $f(\xi) \sim \exp(\xi^2)$ and thus:
  \[
    \chi(\xi) = f(\xi) \exp\left(-\frac{\xi^2}{2}\right) \sim \exp\left(\frac{\xi^2}{2}\right)
  \]
  As $\xi \to \infty$, $\exp(\xi^2/2)$ diverges and so $\chi$ cannot be normalisable.
\end{proof}
We require our eigenfunctions to be normalisable and so the series must terminate to a finite polynomial.
Looking at our recurrence relation, we see that for there to exist $N \in \N_0$ such that $a_{N + 2} = 0$ but $a_{N} \neq 0$, we must have:
\[
  a_{N + 2} = \frac{2N - \varepsilon + 1}{(N + 1)(N + 2)} a_N = 0 \iff 2N - \varepsilon + 1 = 0 \iff \varepsilon = 2N + 1
\]
for some $N \in \N_0$.

By definition $\varepsilon = 2E/\hbar \omega$, and so the eigenvalues are given by:
\[
  E = E_N = \left(N + \frac{1}{2}\right) \hbar \omega
\]
We see that the ground state energy is $E_0 = \hbar \omega/2$ and the energy levels are equally spaced with $E_{N + 1} - E_N = \hbar \omega$.
This means that our system can only absorb or emit photons whose angular frequency is an integer multiple of $\omega$, resulting in equally spaced spectral lines.

The corresponding eigenfunction for the eigenvalue $E_N$ is:
\[
  \chi_N(x) = f_N(\xi) \exp\left(-\frac{\xi^2}{2}\right)
\]
where $f_N$ is the finite polynomial with coefficients following \cref{coeffRel} when $\varepsilon = 2N + 1$.
Since the last non-zero coefficient is $a_N$, $f_N$ is a polynomial of order $N$.
So since $f_N(\xi)$ is an even or odd function of $\xi$, if $N$ is even, so is $f_N$ and if $N$ is odd, so is $f_N$.
We call $f_N$ the \textit{$N$-th Hermite polynomial}.
If we take $a_0$ or $a_1$ as $1$, for even and odd $N$ respectively, then we obtain the un-normalised eigenfunctions $\chi_N$:
\begin{center}
\begin{tabular}{c|c|c|c}
  $N$ & $E_N$ & $f_N$ & $\chi_N(\xi)$ \\
\hline
0 & $\frac{1}{2} \hbar \omega$ & 1 &  $\exp\left(-\frac{\xi^2}{2}\right)$ \\
1 & $\frac{3}{2} \hbar \omega$ & $\xi$ &$\xi \exp\left(-\frac{\xi^2}{2}\right)$ \\
2 & $\frac{5}{2} \hbar \omega$ & $1 - 2\xi^2$ &$(1 - 2\xi^2)\exp\left(-\frac{\xi^2}{2}\right)$ \\
3 & $\frac{7}{2} \hbar \omega$ & $\xi - \frac{2}{3} \xi^3$ & $(\xi - \frac{2}{3} \xi^3) \exp\left(-\frac{\xi^2}{2}\right)$ \\
$\vdots$ & $\vdots$ & $\vdots$ \\
\end{tabular}
\end{center}
We can generate scaled versions of the above the Hermite polynomials, with leading coefficient $2^{n}$, known as the \textit{physicists Hermite polynomial}, using the equation:
\[
  f_n(\xi) = (-1)^{n} e^{\xi^2} \deriv[n]{}{\xi}\left(e^{-\xi^2}\right)
\]
\section{Free Particles}
\subsection{Normalisation Issues} \label{normIssSec}
Consider the TISE with $U(x) \equiv 0$:
\begin{align*}
  -\frac{\hbar^2}{2 m} \chi''(x) + E\chi(x) &= 0 \\
  \iff \chi''(x) + \frac{2mE}{\hbar^2} \chi(x) &= 0 \\
  \iff \chi''(x) + k^2 \chi &= 0
\end{align*}
where $k^2 = \frac{2mE}{\hbar^2}$.
This has solution:
\[
  \chi(x) = Ce^{ikx} + De^{-ikx}
\]
giving the wavefunction:
\[
  E_k = \frac{\hbar^2 k^2}{2m} \text{ and } \chi_k(x) = Ce^{ikx}
\]
Substituting this into the TISE, we obtain the wavefunctions:
\[
  \psi_k(x, t) = \chi_k(x) e^{-i E_k t/k} = C \exp\left[i\left(kx - \frac{\hbar k^2}{2m}t\right)\right]
\]
These solutions are not square integrable as, for $C \neq 0$:
\[
  \int_{-\infty}^{\infty} |\psi_k(x, t)|^2 \d{x} = \infty
\]
If $C = 0$, then $\psi_k$ is the unphysical null state and so these $\psi_k$ are not normalisable.
We can hope to bypass this problem by building a linear superposition of these $\chi_k$ which is normalisable.
\subsection{Gaussian Wavepacket}
Since the above solutions are indexed by $k \in \R$, we can write a wavefunction $\psi$ as a continuous linear combination:
\begin{align*}
  \psi(x, t) &= \int_{-\infty}^{\infty} A(k) \psi_{k}(x, t) \d{k} \\
             &= \int_{-\infty}^{\infty} A(k) \exp\left[i\left(kx - \frac{\hbar k^2}{2m}t\right)\right] \d{k}
\end{align*}
where $A(k) \in \R$.

One possible option for $A$ is:
\[
  A(k) = A_{\text{GP}}(k) = \exp\left[-\frac{\sigma}{2}(k - k_0)^2\right]
\]
where $\sigma \in \R^{+}$ and $k_0 \in \R$.
This corresponds to the \textit{Gaussian wave packet}.
\begin{align*}
  \psi_{\text{GP}}(x, t) &= \int_{-\infty}^{\infty} A_{\text{GP}}(k) \psi_k(x, t) \d{k} \\
                         &= \int_{-\infty}^{\infty} \exp[F(k)] \d{k}
\end{align*}
where we define $F(k)$ as:
\begin{align*}
  F(k) &= - \frac{\sigma}{2}(k - k_0)^2 + ikx - i \frac{\hbar k^2}{2m} t \\
       &= - \frac{1}{2}\left(\sigma + \frac{i\hbar t}{m}\right)k^2 + (k_0 \sigma + ix)k - \frac{\sigma}{2}k^2_0 \\
       &= - \frac{1}{2} \alpha k^2 + \beta k + \delta
\end{align*}
where we define:
\[
  \alpha = \sigma + \frac{i\hbar t}{m},\ \beta = k_0 \sigma + ix,\ \delta = - \frac{\sigma}{2} k^2_0
\]
so that we can complete the square as:
\[
  F(k) = - \frac{\alpha}{2} \left(k - \frac{\beta}{\alpha}\right)^2 + \frac{\beta^2}{2\alpha} + \delta
\]
Since $\alpha$, $\beta$, and $\delta$ do not depend on $k$, we can pull them out of the integral:
\[
  \psi_{\text{GP}}(x, t) = \exp\left[\frac{\beta^2}{2\alpha} + \delta\right]  \int_{-\infty}^{\infty} \exp\left[-\frac{\alpha}{2}\left(k - \frac{\beta}{\alpha}\right)^2\right] \d{k}
\]
We want to try and relate this integral to the Gaussian integral.
We split up:
\[
  \frac{\beta}{\alpha} = \Re\left(\frac{\beta}{\alpha}\right) + i \Im\left(\frac{\beta}{\alpha}\right)
\]
Letting $\widetilde{k} = k - \frac{\beta}{\alpha}$ and $\nu = \im[\beta/\alpha]$:
\begin{align*}
  \psi_{\text{GP}}(x, t) &= \exp\left[\frac{\beta^2}{2\alpha} + \delta\right] \int_{-\infty}^{\infty} \exp\left[-\frac{\alpha}{2}\left(k - \frac{\beta}{\alpha}\right)^2\right] \d{k} \\
                         &= \exp\left[\frac{\beta^2}{2\alpha} + \delta\right] \int_{-\infty - i\nu}^{\infty - i\nu} \exp\left[-\frac{\alpha}{2}\widetilde{k}^2\right] \d{\widetilde{k}}
\end{align*}
We know from IA Differential Equations/IA Probability that:
\[
  \int_{-\infty}^{\infty} \exp[-a x^2] \d{x} = \sqrt{\frac{\pi}{a}}
\]
so by appealing to the Cauchy residue theorem, by constructing a closed contour along the real line, and, the line $\R - i\nu$, joined at the ends and then taking the ends off to $\pm \infty$, we obtain that:
\[
  \int_{-\infty - i\nu}^{\infty - i\nu} \exp\left[-\frac{\alpha}{2}\widetilde{k}^2\right] \d{\widetilde{k}} = \int_{-\infty}^{\infty} \exp\left[-\frac{\alpha}{2}x\right] \d{x} = \sqrt{\frac{2\pi}{\alpha}}
\]
Thus:
\begin{align*}
  \psi_{\text{GP}}(x, t) &= \sqrt{\frac{2\pi}{\alpha}}\exp\left[\frac{\beta^2}{2\alpha} + \delta\right] \\
                         &= \sqrt{\frac{2\pi}{\sigma + \frac{i\hbar t}{m}}}\exp\left[\frac{(k_0 \sigma + ix)^2}{2\sigma + \frac{2i \hbar t}{m}} - \frac{\sigma}{2} k^2_0\right]
\end{align*}
As $x \to \pm \infty$, $\psi_{\text{GP}}$ decays exponentially and so it is square integrable.
Thus $\psi_{\text{GP}}$ is a normalisable solution to the TISE for a free particle.
We pick $C$ as:
\[
  C = \left[\int_{-\infty}^{\infty} |\psi_{\text{GP}(x, t)}|^2 \d{x}\right]^{-1/2}
\]
So that $\overline{\psi}_{\text{GP}} = C \psi_{\text{GP}}$ has $\norm{\overline{\psi}_{\text{GP}}} = 1$.

The position probability distribution for this state can then we shown to be:
\begin{align*}
  \rho_{\text{GP}}(x, t) &= |\overline{\psi}_{\text{GP}}|^2 \\
                         &= \sqrt{\frac{\sigma}{\pi\left(\sigma^2 + \frac{\hbar^2 t^2}{m^2}\right)}} \exp\left[-\frac{\sigma\left(x - \frac{\hbar k_0 t}{m}\right)^2}{\sigma^2 + \frac{\hbar^2 t^2}{m^2}}\right]
\end{align*}
This is symmetric about its peak at $\frac{\hbar k_0 t}{m}$ for all $t$ and so we would guess that the expected position is $\frac{\hbar k_0 t}{m}$.
Finding this explicitly, we can show that indeed:
\[
  \langle \hat{x} \rangle_{\overline{\psi}_{\text{GP}}} = \int_{-\infty}^{\infty} \overline{\psi}_{\text{GP}}^{*} \overline{\psi}_{\text{GP}} \d{x} = \frac{\hbar k_0}{m} t
\]
We will define the uncertainty of the position properly later, however, thinking of it as the standard deviation (i.e. the square root of the variance), we can show that:
\[
  \Delta x = \sqrt{\langle \hat{x}^2 \rangle_{\overline{\psi}_{\text{GP}}} - \langle \hat{x} \rangle^2_{\overline{\psi}_{\text{GP}}}} = \sqrt{\frac{1}{2}\left(\sigma + \frac{\hbar^2 t^2}{m^2 \sigma}\right)}
\]
Similarly, for the momentum of the particle represented by $\overline{\psi}_{\text{GP}}$, we can show that:
\[
  \langle \hat{p} \rangle_{\overline{\psi}_{\text{GP}}} = \int_{-\infty}^{\infty} \overline{\psi}_{\text{GP}}^{*} \left(-i \hbar \pderiv{}{x} \overline{\psi}_{\text{GP}}\right) \d{x} = \hbar k_0
\]
with uncertainty:
\[
  \Delta p = \sqrt{\langle \hat{p}^2 \rangle_{\overline{\psi}_{\text{GP}}} - \langle \hat{p} \rangle^2_{\overline{\psi}_{\text{GP}}}} = \frac{\hbar}{\sqrt{2\sigma}}
\]
Interestingly, both of these are independent of time.
We note that at $t = 0$, $\Delta x \Delta p = \hbar/2$ and for $t > 0$, $\Delta x \Delta p > \hbar / 2$.
This is related to the \textit{Heisenberg uncertainty principle} that we will see later in the course.
\subsection{Beam Interpretation}
What would happen if we just ignored the normalisation problems we came across in \cref{normIssSec} and just took:
\[
  \chi_k(x) = e^{i k x}
\]
to be the eigenfunctions of $\hat{H}$ with corresponding stationary states:
\[
  \psi_k(x, t) = A e^{ikx} e^{-\frac{i\hbar k^2 t}{2m}}
\]
For this to make sense, instead of thinking of $\psi_k$ as describing a single particle, we think of it as describing a beam of particles with:
\[
  p_k = \hbar k \text{ and } E_k = \frac{\hbar^2 k^2}{2m}
\]
Instead of interpreting $\rho_k(x, t) = |A|^2$ as the probability density of the position of a single particle, we instead interpret it as the \textit{average density} of particles in the beam.
The probability current (from \cref{probCurrent}) of $\psi_k$ is then:
\begin{align*}
  J_k(x, t) &= - \frac{i \hbar}{2m} \left(\psi^{*}_k \pderiv{\psi_k}{x} - \psi_k \pderiv{\psi^{*}_k}{x}\right) \\
            &= - \frac{i \hbar}{2m} \left(ik|A|^2 + ik|A|^2\right) \\
            &= |A|^2 \cdot \frac{\hbar k}{m} \\
            &= |A|^2 \cdot \frac{p_k}{m}
\end{align*}
which is the product of the average density of the beam $|A|^2$ multiplied by the velocity of the particles, i.e. $J_k$ can be interpreted is the average flux of a beam of particles.

\subsection{Reflection and Transmission Probabilities}
Consider a potential barrier of height $U_0$ and with $a$.
\begin{center}
\begin{tikzpicture}[>=stealth]
  \draw[->, gray!80] (3.6, 1.5) -- (4.4, 1.5);
  \draw[domain=-6:5, smooth, samples=100, gray!80] plot (\x,{exp(-((\x - 4)/0.5)^2)/(0.5 * sqrt(pi))});
  \draw[<-, gray!80] (-2.4, 1.5) -- (-1.6, 1.5);
  \draw[domain=-6:5, smooth, samples=100, gray!80] plot (\x,{exp(-((\x + 2)/0.5)^2)/(0.5 * sqrt(pi))});
  \draw[->] (-5.4, 1.5) -- (-4.6, 1.5);
  \draw[domain=-6:5, smooth, samples=100] plot (\x,{exp(-((\x + 5)/0.5)^2)/(0.5 * sqrt(pi))});

  \draw[->] (-6, 0) -- (5, 0) node[right] {$x$};
  \draw[->] (0, 0) node[below] {0} -- (0, 4) node[right] {$U(x)$};
  \draw[thick] (0, 0) -- (0, 3) node[left] {$U_0$} -- (2, 3) -- (2, 0) node[below] {$a$};
\end{tikzpicture}
\end{center}
Suppose, we have a particle of mass $m$ and energy $E$ (black in the above) coming in from $-\infty$ and scattering on the potential barrier.

In classical mechanics, if $E > U_0$, the particle overcomes the barrier and travels off to $x = \infty$, on the other hand, if $E < U_0$, the particle is reflected back towards $x = -\infty$.

However in quantum mechanics, we can have both transmission and reflection.
Consider a gaussian wavepacket with normalised wavefunction $\psi_{\text{GP}}(x, t)$.
Suppose that the wavepacket is cent at $x_0 \ll 0$ at $t = 0$ with average momentum $\langle p \rangle > 0$ and evolves according to the TDSE, the can be both transmitted or reflected (grey in the above).

The position probability density is then $|\psi_{\text{GP}}(x, t)|^2$ and so the probability the particle is reflected is:
\[
  R = \lim_{t \to \infty} \int_{-\infty}^{0} |\psi_{\text{GP}}(x, t)|^2  \d{x}
\]
and the probability the particle is transmitted is:
\[
  T = \lim_{t \to \infty} \int_{0}^{\infty} |\psi_{\text{GP}}(x, t)|^2  \d{x}
\]
These are called the \textit{reflection coefficient} and \textit{transmission coefficient} respectively.
Since the total probability is conserved for all $t$, we have $R + T = 1$, i.e. a particle must either be transited or reflected.

In the beam interpretation, since $\rho_{\text{GP}}(x, t)$ is the average density of the beam, $R$ is the proportion of incoming particles that are reflected and $T$ is the proposition of incoming particles that are transmitted.
\subsection{Scattering Off a Potential Step}
Consider the potential step:
\[
  U(x) = \begin{cases}
  0 & x \leq 0 \\
  U_0 & x > 0
  \end{cases}
\]
for $U_0 \in \R^{+}$.
For this, we need solve the TISE in two regions.

For $x \leq 0$, $U(x) = 0$ and so:
\[
  \chi''(x) + \frac{2mE}{\hbar^2} \chi(x) = 0
\]
As usual if $E > 0$, then we take $k = \sqrt{\frac{2mE}{\hbar^2}}$, giving:
\[
  \chi_k(x) = A \exp(ikx) + B \exp(-ikx)
\]
In the beam interpretation, the first term is the beam of incident particles and the second term is the beam of reflected particles.

For $x > 0$, $U(x) = U_0$ and so:
\[
  \chi''(x) + \frac{2m(E - U_0)}{\hbar^2} \chi(x) = 0
\]
We then define:
\[
  \overline{k} = \sqrt{\frac{2m}{\hbar^2}(E - U_0)}
\]
which is real if and only if $E \geq E_0$.
\begin{proofcases}
  \begin{case}{$E \geq U_0$}
    In this case $\overline{k} \in \R$ so:
    \[
      \chi_{\overline{k}}(x) = C\exp(i\overline{k} x) + D \exp(i\overline{k} x)
    \]
    In the beam interpretation, first term is the beam of transmitted particles coming from $-\infty$ and the second term is a beam of particles coming from $+\infty$.
    We assume that the beam of particles comes only from $-\infty$ and so $D = 0$.
    Thus:
    \[
      \chi_{k, \overline{k}}(x) = \begin{cases}
      A e^{i k x} + Be^{-ikx} & \text{ if } x \leq 0 \\
      Ce^{i\hbar x} & \text{ if } x > 0
      \end{cases}
    \]
    We need to enforce continuity of $\chi$ and $\chi'$ at $x = 0$.
    For this, we require:
    \[
      A + B = C \text{ and } ikA - ikB = i \overline{k} c \implies B = \frac{k - \overline{k}}{k + \overline{k}} \cdot A \text{ and } C = \frac{2k}{k + \overline{k}} \cdot A
    \]
    and so:
    \[
      \chi_{k, \overline{k}}(x) = \begin{cases}
      A\left(e^{ikx} + \frac{k - \overline{k}}{k + \overline{k}}e^{-ikx}\right) & \text{ if } x \leq 0 \\
      A \cdot \frac{2k}{k + \overline{k}} e^{i\hbar x} & \text{ if } x > 0
      \end{cases}
    \]
    We can also find the probability current for these solutions:
    \begin{align*}
      J_k(x, t) &= \frac{i\hbar}{2m}\left(\chi_k^{*} \pderiv{\chi_k}{x} - \chi_k \pderiv{\chi_k^{*}}{x}\right) \\
              &= \begin{cases}
              \frac{\hbar}{m}(|A|^2 - |B^2|) & \text{ if } x \leq 0 \\
              \frac{\hbar \overline{k}}{m} |C|^2 & \text{ if } x > 0
              \end{cases}
    \end{align*}
  \end{case}
\end{proofcases}
